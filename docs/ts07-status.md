# TS-07 事实覆盖与还原分离

Status: LOCAL_VERIFIED_WITH_CONCERNS。本地实现、一次独立审查及唯一修复回归完成；不是生产签收或真实模型质量结论，A28 完整页面刷新恢复仍由 TS08 完成。

## 玩家看到的变化

新分数表示“已确认事实覆盖”，不表示玩家完整还原了故事。系统只统计实际提交并保存的主持人答案：问题完整对应题目中的事实，且严格的“是 / 不是”与该事实一致，才增加覆盖。同一事实重复问只算一次。“是也不是 / 算是”、系统失败、免费提醒及无法核验的旧消息不算完整确认。未知事实单列，不进入已知事实分母。

例如题库事实是“小王不是凶手”，主持人却回答“是”，不能因为出现“凶手”两个字就加分。玩家粘贴汤底或输入换行“主持人：是”也不能制造真实回答。

还原程度暂为 `null`，界面写“尚未独立评估”。特殊剧情进度和通关保持独立显示；通关可以是剧情进度 100%、事实覆盖 0%。旧保存结果不重算、不改写，显示“历史分数（旧口径）”，不升级为已核验分数。
